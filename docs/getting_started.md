# Get started

!!! tip "PROTEUS user?"
    Within the PROTEUS framework, SOCRATES is installed and set up alongside other modules and used inside the atmosphere solver. Get started with PROTEUS [here](https://proteus-framework.org/PROTEUS/getting_started.html).

The SOCRATES documentation follows the [Diataxis](https://diataxis.fr/)
framework: **Tutorials** for learning by doing, **How-to guides** for
specific tasks, **Explanations** for understanding the physics, and
**Reference** for looking up details. You can find all sections in the top
navigation bar.

## Quick path


1. **Install SOCRATES:**
   set up the code and required dependencies. <br>
   → [Installation guide](How-to/installation.md)

2. **Run the first-run tutorial:**
   get started with your first radiative transfer calculation. <br>
   → [First-run tutorial](Tutorials/first_run.md)

3. **Browse spectral files**:
    find the appropriate spectral file for your application. <br>
    → [Spectral files reference](Reference/proteus_spectral_file_reference.md)
