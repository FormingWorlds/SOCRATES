# Socrates - Suite Of Community RAdiative Transfer codes based on Edwards and Slingo

SOCRATES is a high-performance radiative transfer code used to compute fluxes, heating rates, and radiances in Earth and planetary atmospheres. Developed and maintained by the UK Met Office, it forms the radiative core of the PROTEUS framework.

!!! info "PROTEUS framework"
    This documentation describes the version of SOCRATES as integrated into the exoplanet evolution modelling framework PROTEUS. The original repository MetOffice repository can be found [here](https://github.com/MetOffice/socrates).
